# 群关联监控惩罚插件 (astrbot_plugin_group_monitor) v1.4.0

监控群成员加群事件，如果在指定缓冲时间内未加入目标群，则自动在当前群执行禁言或踢出。

## 新增特性 (v1.4.0)
- **支持自定义规则别名**：在 WebUI 添加条目时可自定义名称（如“主群二群联动”），留空时自动保存为监控群号，告别满屏单调的“监控规则”。
- **指令支持命名**：支持指令末尾附带自定义备注名，不填则默认以群号命名。
- **权限与提醒**：群主/群管理员/Bot管理员均可操作，入群自动 @ 新人提醒。

## 指令说明（群主/群管理员/Bot管理员可用）
- `群监控帮助` / `群互联帮助`：查看指令帮助文档
- `添加群监控 <群1> <群2> [禁言/踢出] [缓冲秒数] [规则名称]`
  - 例1：`添加群监控 111 222`（默认规则名为 111，默认禁言，缓冲60秒）
  - 例2：`添加群监控 111 222 踢出`（默认踢出，缓冲600秒/10分钟）
  - 例3：`添加群监控 111 222 踢出 300 VIP考核群`（带自定义规则名称）
- `群监控列表`：查看当前所有规则名称、序号及惩罚配置
- `删除群监控 <序号>`：删除指定序号的监控规则
- `设置惩罚 <序号> <禁言/踢出> [缓冲秒数]`：调整已有规则的处罚方式及时间
