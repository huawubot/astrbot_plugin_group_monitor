# 群关联监控惩罚插件 (astrbot_plugin_group_monitor) v1.4.1

监控群成员加群事件，如果在指定缓冲时间内未加入目标群，则自动在当前群执行禁言或踢出。

## ⚠️ 部署前提（不满足则功能不生效）

1. **机器人必须同时在监控群和目标群中**（不在目标群时无法校验新人是否已加群）；
2. **机器人必须在监控群具有管理员权限**，否则禁言/踢出必然失败；
3. **仅支持 OneBot V11 平台**（NapCat / Lagrange 等，事件 `raw_message` 为 OneBot dict 且含 `notice_type`）；QQ 官方平台收不到入群事件；
4. 添加规则时插件会自动做上述自检，不满足会明确警告，不会静默失效。

## 指令说明（群主/群管理员/Bot管理员可用）

- `群监控帮助` / `群互联帮助`：查看指令帮助文档
- `添加群监控 <群1> <群2> [禁言/踢出] [缓冲秒数] [规则名称] [禁言时长秒数]`
  - 例1：`添加群监控 111 222`（默认规则名为 111，默认禁言，缓冲60秒）
  - 例2：`添加群监控 111 222 踢出`（默认踢出，缓冲600秒/10分钟）
  - 例3：`添加群监控 111 222 踢出 300 VIP考核群`（带自定义规则名称，名称不要带空格）
  - 例4：`添加群监控 111 222 禁言 60 主群二群 7200`（禁言2小时）
  - 同一监控群只允许一条规则；重复添加会被拒绝
- `群监控列表`：查看当前所有规则名称、序号与惩罚配置
- `删除群监控 <序号>`：删除指定序号的监控规则
- `设置惩罚 <序号> <禁言/踢出> [缓冲秒数] [禁言时长秒数]`：调整已有规则
  - 不带缓冲秒数时按惩罚类型取默认：禁言 60 秒 / 踢出 600 秒

## 参数语义

- **缓冲秒数（delay）**：新人加入监控群后，多久执行一次目标群校验（不是禁言时长）。
- **禁言时长（mute_duration）**：仅惩罚方式=禁言时生效，默认 86400 秒（24 小时），WebUI 与指令均可配置。
- **校验失败处理**：目标群成员查询会重试 3 次；仍失败时**不执行惩罚**，并在群里提示管理员人工确认（不会误罚）。
